# Page mockups

HTML fragments from the brainstorming visual companion (2026-10-28), shown to the owner while
designing the readiness page. The numbers are made up. They use the companion's frame CSS
classes, so opened on their own they render unstyled; read them for layout and content.

- `layout.html`: the first page layout (status strip, matchup card, press log) and the
  "what does Go do" choice. The owner picked **both**.
- `admin-test-modal.html`: the admin test modal.
- `tests.html`: admin and coach tests side by side. The owner kept calls 1 and 2; call 3 (a
  beacon at each booth) was wrong, because booths have no beacons.
